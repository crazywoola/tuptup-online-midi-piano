# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
**Security → Report a vulnerability** flow for this repository and include:

- A description of the impact
- Reproduction steps or a minimal proof of concept
- Affected browser and operating system
- Any suggested mitigation

Do not include access tokens, private URLs, hardware serial numbers, or personal
MIDI performance data. You can expect an initial acknowledgement within seven
days. Please allow time for a fix before publicly disclosing the report.
